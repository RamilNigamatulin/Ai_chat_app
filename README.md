# AIChatApp - Чат-приложение с ИИ

AIChatApp - это мультиплатформенное приложение для общения с искусственным интеллектом, разработанное с использованием Flutter. Приложение поддерживает работу как с OpenRouter.ai, так и с VseGPT.ru, предоставляя гибкие возможности для взаимодействия с различными языковыми моделями.

Приложение построено как многостраничное: нижняя панель навигации содержит четыре раздела — **Чат**, **Статистика**, **Расходы** и **Настройки**. Провайдер, API ключ и параметры генерации можно менять прямо во время работы приложения, без перезапуска.

## Поддержка API

### OpenRouter.ai
- Баланс отображается в долларах ($)
- Стоимость сообщений рассчитывается в долларах за миллион токенов
- Широкий выбор языковых моделей от разных провайдеров
- Единый API для доступа к различным моделям

### VseGPT.ru
- Баланс отображается в рублях (₽)
- Стоимость сообщений рассчитывается в рублях за тысячу токенов
- Доступ к популярным моделям с оплатой в рублях
- Оптимизировано для пользователей из России

Выбор провайдера выполняется на странице «Настройки»; базовый URL, валюта и формат цен определяются автоматически.

## Навигация

| Вкладка | Экран | Назначение |
|---------|-------|------------|
| Чат | `ChatScreen` | Общение с моделью, выбор модели, баланс, работа с историей |
| Статистика | `StatsScreen` | Статистика использования токенов по моделям |
| Расходы | `SpendingScreen` | График расходов по дням (7/14/30 дней) |
| Настройки | `SettingsScreen` | Провайдер API, API ключ, max tokens, температура |

Переключение страниц реализовано через `NavigationBar` + `IndexedStack` (внутреннее состояние каждой страницы, включая чат, сохраняется при переключении).

## Структура проекта

Основные директории и файлы:

- `lib/` - Основной код приложения
  - `main.dart` - Точка входа, тема (Material 3), локализация (ru/en), `AppShell` с нижней навигацией и `ErrorBoundaryWidget`
  - `api/` - Модули для работы с API
    - `openrouter_client.dart` - Универсальный клиент для работы с OpenRouter и VseGPT
  - `models/` - Модели данных
    - `message.dart` - Модель сообщения с поддержкой токенов и стоимости
  - `providers/` - State management
    - `chat_provider.dart` - Провайдер для управления состоянием чата
  - `services/` - Сервисы
    - `config_service.dart` - Сервис конфигурации (провайдер, API ключ, параметры генерации)
    - `database_service.dart` - Сервис для работы с локальной базой данных
    - `analytics_service.dart` - Сервис для сбора и анализа статистики
  - `screens/` - Экраны приложения
    - `chat_screen.dart` - Основной экран чата
    - `stats_screen.dart` - Экран статистики использования токенов
    - `spending_screen.dart` - Экран графика расходов по дням
    - `settings_screen.dart` - Экран настроек провайдера и API ключа
- `test/` - Тесты приложения
  - `navigation_test.dart` - Smoke-тест навигации по четырём страницам
  - `widget_test.dart` - Шаблонный тест счётчика (не соответствует текущему UI)
- `android/`, `windows/` - Платформо-зависимые конфигурации (в репозитории нет директорий `ios/` и `linux/`)
- `assets/` - Ресурсы приложения
- `pubspec.yaml` - Зависимости проекта

## Основные модули

### ConfigService
- Singleton + `ChangeNotifier` — единый источник настроек приложения
- Хранит выбранный провайдер (OpenRouter/VseGPT), API ключ, `MAX_TOKENS` и `TEMPERATURE`
- Значения по умолчанию берутся из `.env`, изменения пользователя сохраняются в `SharedPreferences`
- Изменения применяются в рантайме (без перезапуска) и уведомляют подписчиков
- Форматирование сумм в валюте текущего провайдера (`$`/`₽`)

### ChatProvider
- Управление состоянием чата и историей сообщений
- Взаимодействие с API (OpenRouter/VseGPT)
- Отслеживание баланса и расходов
- Управление моделями и их настройками
- `refresh()` — перезагрузка списка моделей и баланса после смены настроек
- `getModelUsageStatistics()` / `getDailySpending()` / `getSessionStatistics()` — данные для экранов статистики и расходов

### Message
- Хранение текста сообщений
- Учет использованных токенов
- Расчет стоимости сообщений
- Метаданные (временные метки, модель)

### OpenRouterClient
- Унифицированный интерфейс для работы с API
- Настройки (провайдер, ключ, параметры генерации) берутся из `ConfigService`
- Заголовок `Authorization` формируется на лету по текущему API ключу
- Автоматическое определение провайдера (OpenRouter/VseGPT) и валюты
- Форматирование цен в соответствии с провайдером
- Без API ключа баланс возвращается как нулевой (запрос к API не выполняется)
- Модели по умолчанию содержат `pricing` и `context_length` (защита UI от null)
- Обработка ошибок и повторные попытки

### DatabaseService
- Локальное хранение истории сообщений
- Кэширование данных
- Экспорт истории
- Статистика использования
- `getDailySpending()` — агрегация стоимости сообщений по календарным дням (SQL `GROUP BY`)

### AnalyticsService
- Сбор статистики использования
- Анализ эффективности моделей
- Отслеживание времени ответа
- Анализ использования токенов
- Статистика текущей сессии (`getStatistics()`)

## Функциональность приложения

### Основные возможности
- Обмен сообщениями с различными языковыми моделями
- Выбор модели из доступного списка
- Отображение баланса в соответствующей валюте ($/₽)
- Подсчет стоимости каждого сообщения
- Отслеживание использования токенов

### Управление чатом
- Сохранение истории сообщений
- Экспорт истории в JSON
- Экспорт логов
- Копирование сообщений в буфер обмена
- Очистка истории

### Настройки (без перезапуска приложения)
- Выбор провайдера API: OpenRouter.ai или VseGPT.ru
- Ввод/изменение API ключа (с маскированием ввода)
- Настройка максимального количества токенов ответа
- Настройка температуры генерации (0.0 - 2.0) с валидацией
- Автоматическое обновление списка моделей и баланса после сохранения

### Аналитика
- **Статистика токенов**: всего сообщений и токенов, разбивка по моделям (количество, токены, доля в %)
- **Расходы по дням**: суммарные траты за период, столбчатый график и список по дням, выбор периода (7/14/30 дней)
- Анализ времени ответа и статистика текущей сессии
- Экспорт аналитических данных

### Интерфейс
- Тёмная тема на основе Material 3
- Нижняя навигация из четырёх разделов (`NavigationBar`)
- Адаптивный дизайн
- Поддержка русского и английского языков (локаль по умолчанию — русский)
- Информативные уведомления (SnackBar)

### Технические особенности
- Кроссплатформенность (Android, Windows; iOS/Linux-конфигурации в репозитории отсутствуют)
- Локальное хранение данных (SQLite через sqflite, настройки — SharedPreferences)
- Оффлайн доступ к истории
- Обработка ошибок сети и глобальная обработка ошибок (`ErrorBoundaryWidget`)
- Отсутствие `.env` не критично: недостающие настройки вводятся на странице «Настройки»
- Android-часть переведена на Gradle Kotlin DSL (`build.gradle.kts`), Gradle 9.3.1, Java 17

## Начало работы

1. Клонируйте репозиторий
2. (Опционально) Создайте файл `.env` на основе `.env.example` и укажите значения по умолчанию
3. Следуйте инструкциям в [INSTALL.md](INSTALL.md) для установки зависимостей и запуска
4. Запустите приложение и введите провайдер и API ключ на странице «Настройки»

## Конфигурация

Конфигурация имеет два уровня:

1. **Файл `.env`** — значения по умолчанию (необязателен, ошибки загрузки не критичны):
   - `OPENROUTER_API_KEY` - API ключ по умолчанию (OpenRouter.ai или VseGPT.ru)
   - `BASE_URL` - URL API (https://openrouter.ai/api/v1 или https://api.vsetgpt.ru/v1); по нему определяется провайдер по умолчанию
   - `MAX_TOKENS` - Максимальное количество токенов для ответа (по умолчанию 1000)
   - `TEMPERATURE` - Температура генерации (по умолчанию 0.7)
   - `DEBUG`, `LOG_LEVEL` - Отладочные параметры

2. **Страница «Настройки»** — приоритетные значения на время работы приложения (сохраняются в `SharedPreferences`):
   - Провайдер API (OpenRouter.ai / VseGPT.ru)
   - API ключ
   - Максимальное количество токенов
   - Температура генерации

- `test/navigation_test.dart` — smoke-тест навигации: приложение собирается, отображает нижнюю панель с четырьмя страницами (Чат, Статистика, Расходы, Настройки) и корректно переключается между ними (включая содержимое страниц настроек, статистики и расходов). **Проходит.**
